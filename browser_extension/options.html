Use http://127.0.0.1:8000 locally, or your remote server’s HTTPS address. Saving a remote address asks permission to connect to that server.
In Synapse, open Settings → AI Access → New Browser Token and name it “Browser extension”. Paste it here. The token stays in this browser and is not synced. It keeps working across restarts until you revoke it in Synapse. Leave it empty for localhost.
While this browser is connected, your phone can use its campus/VPN access and publisher sign-ins. Saving asks permission to read publisher pages. Requests expire promptly if this browser cannot accept them; nothing waits for a later reconnect. Interactive CAPTCHAs may need your attention here.
